# وسام — مولّد شهادات التقدير (Kamirty.AI)

يعمل بالكامل في متصفح المستخدم، بلا خادم ولا قاعدة بيانات.

| الملف | الاستخدام |
|---|---|
| `blogger-embed.html` | **للصق داخل صفحة بلوجر** (الطريقة الموصى بها) |
| `index.html` | صفحة مستقلة لو أردت استضافتها لاحقًا على `wisam.kamirtyai.com` |

## الدمج في بلوجر
1. بلوجر ← الصفحات ← صفحة جديدة، والعنوان «وسام - مولّد شهادات التقدير».
2. بدّل المحرر إلى **عرض HTML** (أيقونة القلم ← HTML view).
3. الصق محتوى `blogger-embed.html` كاملًا ثم انشر.
4. في الإعدادات الجانبية للصفحة: خيارات ← لا تسمح بالتعليقات.
5. أضف رابط الصفحة في قائمة الموقع («وسام» بجانب «مولّد الإنفوجرافيك»).

ملاحظات: كل الأنماط محصورة داخل `.shp` فلا تتعارض مع القالب، وعند الطباعة تُخفى عناصر المدونة وتُطبع الشهادات فقط (صفحة لكل طالب).
لا تعدّل الكود من المحرر المرئي (Compose) بعد اللصق، فقد يغيّره بلوجر.
