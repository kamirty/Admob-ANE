# جاوب — منصة ألعاب تعليمية

منصة ويب عربية (RTL) تحتوي على ألعاب تعليمية للأطفال والطلاب. تعمل مباشرة في المتصفح بدون أي خادم أو مكتبات.

## التشغيل
افتح الملف `index.html` في المتصفح، أو شغّل خادماً محلياً:

```bash
cd jawab && python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

## الألعاب
| اللعبة | الفكرة |
|---|---|
| ❓ سؤال وجواب | أسئلة اختيار من متعدد في العلوم والجغرافيا واللغة العربية، مع مؤقت لكل سؤال |
| ➗ تحدي الحساب | أكبر عدد من المسائل في 60 ثانية، بثلاثة مستويات (سهل/متوسط/صعب) |
| ✅ صح أم خطأ | جمل سريعة وقرار خلال 8 ثوانٍ |
| 🧠 لعبة الذاكرة | مطابقة الصورة مع الكلمة العربية |
| 🔤 رتّب الحروف | ترتيب الحروف لتكوين اسم الصورة |

## المزايا
- ملف لاعب محلي: الاسم، مجموع النقاط، المستوى (كل 100 نقطة = مستوى)، وأفضل نتيجة لكل لعبة.
- نجوم (0–3) حسب النتيجة، ورسائل تشجيعية.
- تصميم متجاوب للجوال مع دعم الوضع الداكن.

## البنية
```
jawab/
├── index.html          الشاشات: الترحيب، الرئيسية، اللعبة، النتيجة
├── css/style.css
└── js/
    ├── storage.js      حفظ ملف اللاعب في localStorage
    ├── data.js         المحتوى التعليمي (الأسئلة والكلمات)
    ├── app.js          التنقل بين الشاشات والمؤقت والنتائج
    └── games/          لعبة واحدة في كل ملف
```

## إضافة محتوى أو لعبة جديدة
- **أسئلة جديدة:** أضفها في `js/data.js` (يمكن إضافة مادة جديدة داخل `quiz`).
- **لعبة جديدة:** أنشئ ملفاً في `js/games/` يضيف كائناً إلى `window.JawabGames` بالحقول
  `id, title, desc, icon, color, start(ctx)`، ثم أضف وسم `<script>` له في `index.html`.
  يوفّر `ctx`: `area`, `setScore`, `setProgress`, `startTimer`, `stopTimer`, `toast`, `alive`, `finish(score, max)`.
