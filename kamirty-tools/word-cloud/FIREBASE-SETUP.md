# تفعيل جلسات الـ24 ساعة (Firebase) — مرة واحدة فقط

بدون هذا الإعداد تعمل الأداة كاملة، لكن جلسة «24 ساعة» تكون اتصالاً مباشراً يتطلب بقاء صفحة صاحب الجلسة مفتوحة.
بعده تصبح جلسات الـ24 ساعة سحابية: يرسل الناس إجاباتهم حتى لو أُغلقت الصفحة. (جلسات «الساعة» لا تستخدم Firebase أبداً.)

> قد تختلف أسماء القوائم قليلاً في واجهة Firebase، والفكرة واحدة.

## 1) أنشئ مشروعاً
1. ادخل إلى <https://console.firebase.google.com> بحساب Google.
2. اضغط **Create a project / إنشاء مشروع**، وسمّه مثلاً `kamirty-wordcloud`.
3. عطّل **Google Analytics** (لا نحتاجه) ثم **Create project**.

## 2) أنشئ قاعدة البيانات
1. من القائمة الجانبية: **Build ← Realtime Database ← Create Database**.
2. الموقع: **Belgium (europe-west1)** — الأقرب للمنطقة العربية.
3. اختر **Start in locked mode** ثم **Enable**.
4. انسخ رابط القاعدة الظاهر أعلى الصفحة، ويشبه:
   `https://kamirty-wordcloud-default-rtdb.europe-west1.firebasedatabase.app`

## 3) الصق قواعد الأمان
1. في صفحة Realtime Database افتح تبويب **Rules**.
2. احذف كل ما فيه، والصق محتوى الملف [`firebase-rules.json`](firebase-rules.json)، ثم **Publish**.

هذه القواعد تمنع أي شخص من قراءة قائمة الجلسات أو حذفها أو تعديلها، وتسمح للمشارك فقط بإضافة إجابة قصيرة في جلسة مفتوحة لم تنتهِ مدتها، ولا تتجاوز مدة أي جلسة 24 ساعة.

## 4) فعّل الدخول المجهول
**Build ← Authentication ← Get started ← Sign-in method ← Anonymous ← Enable ← Save**.

(يُستخدم لإثبات أن صاحب الجلسة هو وحده من يوقفها أو يمددها أو يحذفها، دون أن يسجّل أحد حساباً.)

## 5) انسخ مفتاح المشروع
1. اضغط ⚙ بجانب **Project Overview ← Project settings**.
2. في أسفل الصفحة **Your apps** اضغط أيقونة الويب `</>`، اكتب أي اسم، ثم **Register app**.
3. انسخ قيمة `apiKey` (تبدأ بـ `AIza`).

> مفتاح الويب في Firebase ليس سرياً؛ الحماية تأتي من قواعد الأمان في الخطوة 3.

## 6) ضع القيمتين في كود الأداة
في كود بلوجر ابحث عن:

```html
data-fb-key="ضع-apiKey-هنا" data-fb-db="ضع-databaseURL-هنا"
```

واستبدل النصين بالقيمتين، مثلاً:

```html
data-fb-key="AIzaSy...." data-fb-db="https://kamirty-wordcloud-default-rtdb.europe-west1.firebasedatabase.app"
```

ثم انشر التدوينة. عند إنشاء جلسة سترى خيار **«24 ساعة — سحابية»**.

## الحدود المجانية (خطة Spark)
- 1 غيغابايت تخزين، و10 غيغابايت تنزيل شهرياً، و100 اتصال متزامن.
- المشاركون لا يفتحون اتصالاً دائماً؛ الاتصال الدائم فقط لصاحب الجلسة وصفحته مفتوحة.
- إذا تجاوزت الحد تتوقف الخدمة مؤقتاً ولا تُخصم أي أموال (لا توجد بطاقة).
- إن فشل إنشاء جلسة سحابية لأي سبب، تبدأ الأداة جلسة مباشرة تلقائياً وتعرض سبب الفشل.
